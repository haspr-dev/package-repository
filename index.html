Haspr Debian / Ubuntu Repository

Official APT package repository for Haspr CLI, background agent, and backend API.

⚡ Quick Setup (Automated)

Run the official setup script to install the GPG key and add the repository:

curl -fsSL https://haspr-dev.github.io/debian-repository/setup.sh | sudo bash

Then install the package you need:

sudo apt install haspr

🛠️ Manual Setup (Step-by-Step)

1. Install required tools:

sudo apt-get update && sudo apt-get install -y curl ca-certificates

2. Download and verify the Haspr GPG key:

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://haspr-dev.github.io/debian-repository/haspr-archive-keyring.gpg | sudo tee /etc/apt/keyrings/haspr-archive-keyring.gpg > /dev/null

3. Add the APT source repository:

cat << 'EOF' | sudo tee /etc/apt/sources.list.d/haspr.sources
Types: deb
URIs: https://haspr-dev.github.io/debian-repository
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/haspr-archive-keyring.gpg
EOF

4. Update and install:

sudo apt-get update
sudo apt-get install haspr

📦 Available Packages

  • haspr (or go-haspr-cli) — Fast CLI, auth agent, and Git/Docker/AWS/K8s credential helpers. (Architectures: amd64, arm64)
  • haspr-api-ce — Community Edition backend API server package. (Architecture: all)
